# T&L Tech Website

## Preview locally

Open `index.html` in a browser, or run a local static server from this folder:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy

This is a static HTML, CSS and JavaScript website. Upload the contents of this folder to your static hosting provider (for example GitHub Pages, Netlify or Vercel static hosting). Keep the image and video files beside `index.html`.

## Included

- Full-bleed hero video featuring the founders
- Founder introduction, services and portfolio
- GapMap and SmartMoney solution stories
- De Legacy and LRO Media collaboration showcases
- Responsive navigation, portfolio filters and project detail modal
- Contact form that prepares a WhatsApp message

The existing WhatsApp number, phone number, email and social profiles from the original site have been retained.
